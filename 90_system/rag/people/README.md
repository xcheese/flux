# People RAG

本目录用于长期积累 experts / people lens 的本地材料索引、摘要、时间线和人物还原笔记。

核心目标：提升专家团人物还原度，让回答更像该人物会如何注意、判断、反问和表达，而不是只套用抽象模型。

## Rules

- 不默认保存未授权的整本付费书、盗版 PDF、完整付费课程或大段版权文本。
- 优先保存来源索引、章节定位、短摘录、摘要、主题卡片和自有分析。
- 公开网页、官方材料、公开访谈、公开视频、公开字幕可按来源许可和实际可访问性整理。
- 活跃人物的最新动态必须标注抓取日期和来源层级。
- 已故人物的去世后事件只做 historical lens inference，不归因为本人真实观点。

## Directory Convention

- `people/<person-id>/source_notes/`: 来源摘要和主题卡片
- `people/<person-id>/timelines/`: 时间线
- `people/<person-id>/style_notes/`: 口吻、判断节奏、anti-rendering patterns
- `people/<person-id>/live_signals/`: 最新公开动态的轻量记录
