# AI 高价值使用地图

## 摘要

这是个人知识库里用于判断“什么时候值得高质量消耗 token”的核心框架。

核心公式：

```text
高价值使用 = 复杂信息 × 多维推理 × 可复用闭环
```

## 使用方式

- 在开启高成本 AI 对话前，先判断问题是否具备复杂信息、多维推理和可复用闭环。
- 优先投入能沉淀为资产的任务：决策系统、工作流、模板、知识库、复盘机制。
- 减少对无目标闲聊、纯搬运摘要、不可复用重复提问的高成本投入。
