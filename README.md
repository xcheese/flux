# 个人成长知识库：AI 方向第一版

这个知识库先保持轻量，目标是跑通一个循环：

```text
收集资料 -> 初步消化 -> 沉淀概念/工具/项目 -> 输出复盘
```

第一版不追求全自动，也不追求目录完美。先保证每天/每周能持续产生有价值的 Markdown 记录。

## 目录

```text
00_inbox/                  临时收集，未处理内容
10_raw/                    原始资料
  links/                   你给的网页、视频、帖子链接
  videos/                  视频类资料记录
  posts/                   社媒帖子、小红书、抖音等
  articles/                文章、博客、官方文档

20_wiki/                   消化后的知识
  ai/                      AI 主题页
  concepts/                概念卡片
  tools/                   需要掌握的 AI 工具
  skills/                  方法和能力

30_projects/               实践项目和学习计划
40_outputs/                输出物
  daily_ai/                每日 AI 高价值信息
  weekly_reviews/          每周复盘

90_templates/              模板
99_assets/                 图片、转录、附件
```

## 链接投喂流程

你的动作尽量保持简单：只需要把链接发过来。

后续处理由 LLM 完成：

1. 保存链接到 `10_raw/links/`。
2. 尝试获取标题、作者、发布时间、正文、字幕、转录或页面可见内容。
3. 提取核心摘要、高价值点、可信度、适用场景和可行动作。
4. 判断是否值得进入 `20_wiki/`、`30_projects/` 或 `40_outputs/`。
5. 如果平台限制导致无法完整抓取，先基于可见信息生成低置信度摘要，并标记需要后续补全。

原则：不要让你承担复制正文、截图、手动转录这些工作。你只负责投喂链接和判断结果是否有用。

## 第一版判断标准

一条资料只要回答这几个问题就够了：

- 它讲了什么？
- 它为什么重要？
- 它和 AI 方向个人成长有什么关系？
- 我能做什么行动？
- 是否值得沉淀成长期笔记？

## 视频/社媒链接处理标准

对于抖音、B站、YouTube、小红书等链接，优先处理这些信息：

- 核心观点：视频到底在讲什么
- 高价值点：哪些内容值得保留，不只是热闹
- 可操作建议：看完之后可以做什么
- 概念沉淀：是否应该形成 wiki 笔记
- 项目转化：是否能变成个人成长或 AI 实践项目
- 噪音过滤：是否存在营销、标题党、二次包装或信息不足

如果能拿到完整文本，就做完整消化；如果只能拿到标题和页面可见内容，就先做初步消化，并在笔记中标记置信度。

## 主动采集标准

每日 AI 信息只保留 3 条，优先一手来源：

- 官方博客、release notes、技术文档
- 研究论文或作者说明
- 高质量 GitHub 项目
- 可信开发者/研究者的一手分享
- 重要产品或模型更新

排除：

- 无一手来源的爆料
- 标题党和营销号二次包装
- 纯情绪观点
- 内容很热但无法指导学习、判断或实践的信息

## 本地 Web 管理服务

当前知识库可以直接启动一个本地 Web 服务：

```bash
npm start
```

默认地址：

```text
http://127.0.0.1:4321
```

第一版能力：

- 自动扫描当前目录下的 Markdown / 文本笔记。
- 提取标题、frontmatter、标签、路径、字数和更新时间。
- 识别 `[[双链]]`，生成关系图谱、出链和反向链接。
- 支持按目录、标签、标题、路径和正文搜索。
- 左侧浏览文件，中间观察整体关系，右侧沉浸阅读单篇内容。
- 点击图谱节点、列表项或双链关系可以切换阅读对象。
